## 0. 조사 방법과 한계 (반드시 먼저 읽을 것)

### 0.1 조사 방법
- WebSearch 약 38회. 유튜브 채널(Warrior Trading, Humbled Trader, SMB Capital, Live Traders, Oliver Velez, Tori Trades), 커뮤니티(Elite Trader, Trade2Win, r/Daytrading, r/algotrading, useThinkScript), 툴 문서(Trade Ideas, Finviz, ThinkOrSwim, Benzinga Pro), 학술논문(SSRN/JFE/arXiv), 퀀트 플랫폼(QuantConnect, Quantpedia, Concretum Group)을 대상으로 검색.

- 원문 대조를 못 한 수치는 `[요약본 기준]` 으로 표기했다. 2번 에이전트가 실제 백테스트 전에 원문 재확인이 필요한 항목이다.

### 0.2 수치 기재 원칙
- **출처에서 확인된 수치만 기재.** 확인 안 된 것은 "수치 미확인"으로 남겼고 그럴듯한 숫자를 채워넣지 않았다.

- 유튜버·교육업체의 승률/수익률 주장은 원문 그대로 옮기되 **반드시 회의적 코멘트를 붙였다.**

### 0.3 조사 전 반드시 알아야 할 기저율 (Base rate)
어떤 방법론을 고르든 이 숫자가 배경에 깔린다.

| 연구 | 표본 | 결과 |
|---|---|---|

## 1. 구현 가능성 판정 기준 — 토스증권 Open API 실제 스펙

이 문서의 **가장 중요한 산출물**은 각 방법론의 구현 가능성 등급이다. 판정 근거가 되는 API 스펙을 먼저 확정한다.
(출처: 공식 OpenAPI 스펙 `openapi.json` 직접 파싱, 공식 개요 문서[^63][^64])

### 1.1 제공되는 시세 데이터

| 엔드포인트 | 반환 필드 | 다건 | Rate limit |
|---|---|---|---|
| `GET /api/v1/prices` | `symbol`, `timestamp`, **`lastPrice`**, `currency` | **최대 200종목/콜** | 초당 10회 (`MARKET_DATA`) |
| `GET /api/v1/candles` | `timestamp, open, high, low, close, volume` | **1종목/콜**, `interval`=**`1m` 또는 `1d` 뿐**, `count` **최대 200봉**, `before`/`nextBefore` 페이징, `adjusted` 옵션 | 초당 5회 (`MARKET_DATA_CHART`) |
| `GET /api/v1/orderbook` | `asks[] / bids[]` (price, volume) | 1종목/콜 | 초당 10회 |
| `GET /api/v1/trades` | 당일 최근 체결 **최대 50건** (price, volume, timestamp) | 1종목/콜 | 초당 10회 |
| `GET /api/v1/stocks` | `name, market, securityType, **isCommonShare**, status, listDate, delistDate, **sharesOutstanding**, leverageFactor` | 최대 200종목/콜 | 초당 5회 (`STOCK`) |
| `GET /api/v1/stocks/{symbol}/warnings` | `warningType` (예: `LIQUIDATION_TRADING` 정리매매), 적용기간 | 1종목/콜 | 초당 5회 |
| `GET /api/v1/market-calendar/US` | dayMarket / preMarket / regularMarket / afterMarket 세션 시각 (KST) | — | 초당 3회 |
| `GET /api/v1/price-limits` | 상/하한가 (**미국주식은 null**) | 1종목/콜 | — |

### 1.2 제공되지 **않는** 데이터 (설계상 결정적 제약)

| 없는 것 | 영향받는 방법론 |
|---|---|
| **뉴스/촉매 피드** | Gap&Go의 촉매 필터, 뉴스 기반 전략 전체 |
| **실적발표 일정** | 실적일 회피 블랙리스트, PEAD |
| **float(유통주식수)** — `sharesOutstanding`(발행주식수)만 있음 | Low-float 스퀴즈, Float rotation |
| **short interest / SSR / halt 이력** | 숏스퀴즈, SSR 회피, 할트 회피 |
| **종목 스크리너·랭킹 API** (거래량 급등 상위, 갭 상위 등) | **모든 스캐닝 전략** — 유니버스를 클라이언트가 사전 확정해 폴링해야 함 |
| **WebSocket** (추후 지원 예정) | 초단위 반응 필요한 전략 |
| **5분/15분봉** | 1분봉 리샘플 필요 (기술적으로는 사소) |
| 프리마켓 캔들이 `1m` 에 포함되는지 **스펙 미명시 → 미확인** | 프리마켓 거래량/갭 기반 전략 전부. **PoC 최우선 검증 항목** |

### 1.3 주문 측 제약 (청산 규칙 설계에 직결)

- 주문타입: **`LIMIT` / `MARKET` 뿐**. `timeInForce`: `DAY` / `CLS`.
- **`LIMIT` + `CLS` = LOC(Limit-On-Close, 장마감 지정가), 미국주식 전용** → **확정적 당일청산 수단으로 사용 가능**. 미국 시장의 종가 경매(closing auction)에 참여하며, MOC 과 달리 가격 상한/하한을 지킬 수 있으나 미체결 가능성이 있다[^51][^52].
- **스톱로스 주문 타입이 없다.** 손절은 클라이언트가 `/prices` 를 폴링하며 감시 → `MARKET` 주문으로 직접 청산해야 한다. **모든 방법론의 손절 규칙은 "폴링 주기 내에 감시 가능한가"로 평가해야 한다.**
- 소수점(금액) 매매 `orderAmount` 는 **US `MARKET` 주문 + 정규장 시간에만** 가능.
- `ORDER` 그룹 rate limit 초당 6회 (KST 09:00~09:10 은 3회 — 미국장에는 무관).

### 1.4 스캐닝 처리량 계산 (핵심)

`/prices` 는 **`lastPrice` 만** 준다. **거래량이 없다.** 이것이 최대 병목이다.

| 계산하려는 값 | 필요 콜 | N=1,000 종목 처리시간 |
|---|---|---|
| 현재가 | `/prices` 200종목/콜, 10 TPS | **0.5초** |
| 갭% (= lastPrice / 전일종가) | 위 + 전일종가는 **1일 1회 캐시**(`/candles?interval=1d`, 1종목/콜, 5 TPS) | 스캔 시 **0.5초** (캐시 구축은 장전 200초) |
| 당일 누적거래량 / RVOL | `/candles?interval=1m` **1종목/콜**, 5 TPS | **200초** ← 병목 |
| VWAP, 시가범위(OR), HOD | 위와 동일 (1분봉 필요) | **200초** |
| ADV(20), ATR(14), 일봉지표 | `/candles?interval=1d&count=200` 1종목/콜, 1일 1회 캐시 | 장전 200초 |
| 스프레드 | `/orderbook` 1종목/콜, 10 TPS | 100초 |

**→ 필연적으로 2단 퍼널(funnel) 구조가 된다:**

```
[T-1일 야간 / 장전 배치]  유니버스 확정(수백~수천) → /stocks(발행주식수·종목유형) + /candles 1d (전일종가·ADV·ATR) 캐시
        ↓
[Stage 1 — 싸고 빠름]     /prices 로 전 유니버스 폴링 (0.5~2초/회) → 갭%·당일등락률 랭킹 → 상위 30~100 shortlist
        ↓
[Stage 2 — 비싸고 느림]   shortlist 만 /candles 1m 폴링 → RVOL·VWAP·OR·HOD 계산 (50종목이면 10초/회)
        ↓
[Stage 3 — 실행]          LIMIT/MARKET 진입 → /prices 폴링으로 스톱 감시 → LIMIT+CLS(LOC)로 당일 확정청산
```

**shortlist 상한**: 1분봉 1분 주기 갱신 기준 **최대 약 300종목**(5 TPS × 60초). 12초 주기라면 **60종목**. 이것이 실질적 설계 상한이다.

### 1.5 구현 가능성 등급 정의

| 등급 | 의미 |
|---|---|
| **A** | 토스 API 단독 가능 — 1분봉/일봉/현재가/호가만으로 계산 가능 |
| **B** | 토스 API + 사전 유니버스/캐시 필요 — 미리 만든 종목 리스트, 발행주식수, 야간 배치 캐시로 가능 |
| **C** | **외부 데이터 필수** — float, 뉴스, 실적일정, short interest 등. 어떤 데이터가 왜 필요한지 명시 |
| **D** | 폴링 REST 로는 지연이 치명적이라 사실상 불가 |

## 2. Gap & Go / 갭 스캐너

### 2.1 Warrior Trading (Ross Cameron) — 프리마켓 갭 스캐너 / 5 Pillars

**출처**: Warrior Trading 공식 스캐너 페이지[^1], Momentum Day Trading Strategies[^3], TradingView "Ross Cameron 5 Pillars Filter" 커뮤니티 스크립트[^2]

**프리마켓 갭 스캐너 조건 [요약본 기준]**[^1]
- 프리마켓 **+5% 이상** 상승
- 거래량 **10만 주 이상**
- 주가 **$2 ~ $20**
- float **5,000만 주 미만**
- 정규장 전환 후에는 "**RVOL 3배 이상 + 신고가 갱신**" 스캔으로 전환

**Gap and Go 변형**: 뉴스로 **+10% 이상** 갭업 → 갭 고점 돌파 시 거래량 동반 진입 → **20~50% 상승 목표** [요약본 기준][^1]

**5 Pillars (커뮤니티 정리판)**[^2]
1. 수요 — 평균 대비 높은 RVOL
2. 수요 — 전일 종가 대비 **±5% 이상** 이동
3. 수요 — 주가를 밀어올리는 **뉴스 이벤트**
4. 수요 — 주가 **$1 ~ $10**
5. 공급 — 유통가능 주식 **1,000만 주 미만** (초공격적 트레이더는 500만 주)

**Momentum 5조건 (공식 블로그)**[^3]
1. 차트패턴: bull flag 또는 flat-top breakout, 손절이 타이트해 **손익비 2:1** 확보
2. 일봉이 강하고 이평선 위, 근처 저항 없음
3. **RVOL 최소 2배 이상**
4. **펀더멘털 촉매** (PR, 실적, FDA, 행동주의 투자자 등)
5. **float 1억 주 미만 선호, 2,000만 주 미만이 이상적**
   추가: 종목이 **이미 당일 +10%** 상태일 것
   → 5,000종목 스캔 시 하루 **10종목 미만** 통과[^3]

**주장되는 성과와 신뢰도 평가**
- Warrior Trading 은 "20~30% 이동 가능 종목" 등의 문구를 쓰지만 **검증된 승률·손익비 통계는 공개되지 않았다.**
- **결정적 회의 근거**: 2022년 4월 **미국 FTC 가 Warrior Trading 및 CEO Ross Cameron 을 허위 수익 주장으로 제소**, **300만 달러 배상 합의**. FTC 는 "광고에 등장한 Cameron 본인의 매매결과를 근거로 '수익성 있고 확장 가능하다'고 주장했으나 **고객 계좌 대다수가 손실**"이라고 적시했다[^47]. 2023년 1월 FTC 는 피해 소비자에게 **290만 달러 이상을 환불**했다[^47].
- **판정**: 이 채널의 **수익률/승률 주장은 신뢰도 최하**. 다만 **스캐너 필터 조건 자체**(갭%, RVOL, float, 가격밴드)는 업계 표준과 일치하므로 **"필터 설계 참고용"으로만** 채택하고, 성과 주장은 전량 폐기할 것.

**구현 가능성**
| 조건 | 등급 | 비고 |
|---|---|---|
| 전일 종가 대비 갭% | **A** | 전일종가 1일 1회 캐시 + `/prices` |
| 주가 밴드 $2~$20 | **A** | `/prices` |
| 당일 +10% | **A** | 동일 |
| RVOL ≥ 2~3 | **B** | 1분봉 20일치 캐시 필요 (§4.2) |
| **프리마켓 거래량 ≥ 10만** | **C (또는 D)** | 1분봉에 프리마켓 포함 여부 **미확인**. 미포함이면 외부 데이터 필수 |
| **float < 5,000만/2,000만** | **C** | `sharesOutstanding`(발행주식수)만 있고 float 없음. 외부 소스 필요 |
| **뉴스 촉매** | **C** | 뉴스 API 없음 |
| → **전체** | **C** | 갭%+가격밴드+RVOL 만 쓰는 축소판이면 **B** |

### 2.2 Bear Bull Traders (Andrew Aziz) — Trade Ideas "Gappers Watch List"

**출처**: Bear Bull Traders 공개 Trade Ideas 설정 문서[^8], Trade Ideas 레이아웃 가이드[^9]

**조건 (확인됨)**[^8]
- 주가 **$5 ~ $250**
- 당일 거래량 **최소 50,000주**
- **ATR ≥ $0.50**
- 전일 종가 대비 **±2% 이상** 이동

**추가로 널리 인용되는 프리마켓 Gappers 스캔 조건 [요약본 기준]**[^4][^5]
- 갭 **±2% 이상**
- 오전 9시(ET)까지 **프리마켓 10만 주 이상** 체결
- **일평균 거래량 50만 주 초과**
- **ATR ≥ $0.50**
- **펀더멘털 촉매 존재**

**진입/청산 (당일청산 관점)**: Aziz 계열은 시가 후 첫 5분봉의 고/저를 기준선으로 삼고 돌파 진입, 반대편 손절, 오후 장에는 신규진입 금지가 일반적 (통념).

**신뢰도**: 승률 주장이 명시되지 않음. 조건 자체는 **가장 보수적이고 재현 가능한 형태**(주가 $5 이상, ATR 절대금액 기준)여서 알고리즘 필터로 적합.

**구현 가능성**: **B** — 주가/갭%/ATR/ADV 전부 일봉+현재가로 계산 가능. 프리마켓 거래량 조건만 빼면 **A**.

### 2.3 TradingView 커뮤니티 / Minervini 계열 갭 진입 (대형주 지향)

**출처**: TradingView Gap Screener 스크립트 요약[^4]

- 갭업 **≥ +3%**
- **프리마켓 거래량 ≥ 20일 평균의 150%**
- RS 라인 > 50
- 주가 > 50 SMA
- **시가총액 ≥ 10억 달러**, 페니주식 제외
- (Minervini Gap-Entry 변형) 첫 되돌림이 **갭의 30% 이하**, 갭 당일 거래량 **> 평균 2배**, 주가가 20 EMA / 50 / 150 / 200 SMA 위

**신뢰도**: 스윙 지향 규칙을 갭 진입에 차용한 것. 당일청산용 통계는 제시되지 않음.

**구현 가능성**: **B** — 시가총액은 `sharesOutstanding × lastPrice` 로 계산 가능(단 발행주식수 기준). 이평선은 일봉 200개로 계산 가능. **프리마켓 거래량만 C**.

### 2.4 Gap and Go 진입/손절 규칙 (구체 수치)

**출처**: Tradezella[^38], ORB Setups[^39]

- 셋업 예시: **프리마켓 갭 6%** → **첫 5분봉 고가(Opening Range High) 돌파** 진입 → 손절은 **OR 저가 하단** → 목표 **2:1 R:R**[^38]
- 첫 5분봉의 고/저를 트리거·리스크 경계로 사용. 돌파 캔들은 **평균 이상 거래량** 필요[^38]
- 익절: **1.5~2R 에서 50% 청산** → 잔량 손절을 본전으로 이동 → 5분봉 구조로 트레일링[^38]
- 계좌 대비 **1트레이드 1~2% 리스크**[^38]
- 갭 크기 선택: "**4~6% 구간**에 엣지가 몰린 트레이더도 있고 **2~4%**가 나은 트레이더도 있다", **최소 4% 갭**으로 노이즈 제거 권장[^39]
- 2%+ 갭 필터에는 **명확한 촉매 + 높은 프리마켓 거래량 + 시가 RVOL 3배 이상**을 함께 걸 것[^39]

**주장되는 성과**: ORB Setups 는 **30일간 190,460건**의 gap-and-go 돌파 표본에서 **롱 돌파 목표달성률 37.4% vs 숏 32.9%** 라고 보고[^39]. 같은 출처의 ORB 평균 승률은 5분/15분/30분에 대해 **52.2% / 52.5% / 52.9%**[^39].
**신뢰도 평가**: 표본이 크고 방향별 비대칭을 제시한 점은 긍정적이나, **상용 스캐너 업체 자체 집계**이며 목표/손절 파라미터·비용가정이 요약본에서 확인되지 않는다. **중간 신뢰도**. 독립 재현 필요.

**구현 가능성**: **A~B** — OR 고/저는 1분봉으로 계산, 진입은 LIMIT/MARKET, 손절은 폴링 감시, 종료는 LOC. 촉매·프리마켓 거래량 조건만 C.

## 3. Momentum / HOD(High of Day) Breakout

### 3.1 SMB Capital — "Stocks In Play" (RVOL > 3 + 신선한 뉴스)

**출처**: SMB Training 블로그[^15]

- **RVOL > 3** 이 "in play" 판정의 핵심 지표. 해당 시각 기준 평균 거래량의 3배 초과[^15]
- **신선한 뉴스 촉매(fresh news catalyst)** 를 자체 스캐너의 gap 컬럼과 함께 확인[^15]
- **Day 2 플레이**: 첫날 in play 였던 종목은 전일 세션에서 만들어진 레벨을 근거로 이튿날에도 추적. 레벨이 있어 오히려 트레이딩이 쉽다는 주장[^15]

**신뢰도**: 프랍펌의 실무 프레임워크로 업계에서 폭넓게 인용되나, **공개된 승률/손익비 수치 없음**. 정성적 프레임워크로 취급.

**구현 가능성**: RVOL **B**, 뉴스 촉매 **C**, Day 2 레벨(전일 고저/VWAP) **A**.
→ **뉴스를 빼고 "RVOL>3 + 전일 레벨" 만 쓰는 축소판이 B로 구현 가능**하며, 이는 후술하는 Zarattini "Stocks in Play" 논문 정의와 사실상 동일하다.

### 3.2 Bull Flag / Flat-top / 첫 되돌림 진입 (Warrior·Humbled 공통)

**출처**: Warrior Trading Bull Flag[^3], Humbled Trader[^14], 커뮤니티 정리[^65][^67]

- 되돌림이 상승폭의 **50%를 초과하지 않을 것**, 그리고 **VWAP 아래로 깨지지 않을 것**[^3]
- 진입: **2~3개 음봉 되돌림 후 신고가를 만드는 첫 캔들**[^3]
- 돌파 캔들 거래량이 **평균의 2배 이상** 확대[^3]
- 손절/트레일: 가격이 **9 EMA** 를 깨면 약세 신호. VWAP 이탈도 약세. 9 EMA 반대편으로 스톱 이동 후 5~10분마다 재조정[^14][^65]
- 저float 페니주식에는 **VWAP + 9 EMA 조합**이 권장됨[^14]. VWAP 위 = 매수우위, VWAP 아래 = 매도우위[^14]

**신뢰도**: 재현 가능한 규칙이지만 **모두 정성적 검증 수준**. 통계 제시 없음.

**구현 가능성**: **A** (shortlist 한정). 1분봉으로 VWAP, 9 EMA, 되돌림 비율, 신고가 갱신 모두 계산 가능. 단 1분봉 폴링 지연(최대 1분 + rate limit) 때문에 **"신고가 갱신 첫 캔들"에 즉시 진입은 불가**하고 **1분 지연 진입**이 된다 → §12 참조.

### 3.3 Trade Ideas RVOL 프리셋

**출처**: Trade Ideas 공식 필터 문서[^7], 프리셋 정리[^9]

- **Relative Volume 필터**: 해당 **시각(time of day)** 기준 **10일 평균 거래량** 대비 현재 거래량. **RVOL 2 이상**을 "in play" 판정 기준으로 사용[^7]
- "High Relative Volume" 스캔: 주가 **$1 ~ $20**[^7]
- **20일 ADV 최소 50만 주** 권장[^7]
- Low Float 채널: **float 2,000만 주 미만**이 "가장 세게 갭 나고 가장 빨리 움직인다"[^7]
- Gappers Watch List: 주가 **$5~$250**, 당일 거래량 **≥ 5만**, **ATR ≥ $0.50**, 전일 대비 **±2%**[^8]
- Volume Today Percent / Volume 5 Minute Percent 등 시간창 기반 거래량 필터 별도 제공[^9]

**구현 가능성**: RVOL **B**, 주가/ATR/ADV **A~B**, float **C**.

### 3.4 Finviz 필터 매핑

**출처**: Finviz 인트라데이 기능 공지[^10], 리뷰[^6]

- Finviz 는 이제 **1분/5분/15분/1시간 인트라데이 타임프레임 스크리닝** 지원 (Elite 플랜에서 실시간)[^10]
- 대표 필터: Average Volume, **Relative Volume**, ATR, 20 SMA, RSI, Volatility[^6][^10]
- RVOL 정의(Finviz): "장 시작 5분간 평균 거래량이 10만, 오늘 같은 5분간 15만이면 RVOL 1.5" — **시간대 기준 누적 비교**이며 하루 종일 지속 갱신[^6]
- ATR 필터 예: **Over 0.25 / Over 0.5** (하루 평균 최소 $0.25 / $0.50 움직임)[^6]

**활용**: Finviz 는 **유니버스 사전 확정(Stage 0)** 용으로 최적. 토스 API 에 스크리너가 없으므로 **Finviz/외부 스크리너로 만든 종목 리스트를 매일 주입**하는 하이브리드가 현실적이다.

## 4. Float Rotation / Low Float 스퀴즈

### 4.1 정의와 임계값

**출처**: Centerpoint Securities[^12], Lightspeed[^13], Humbled Trader[^14]

- **Float rotation = 당일 거래량 ÷ float.** float 500만 주 종목이 2,000만 주 거래되면 rotation = 4[^12]
- **rotation > 1.0** 이면 float 전체가 최소 1회 손바뀜 → 가격 변동성 급증[^12][^13]
- **Low float 기준: 2,000만 주 미만**이 데이트레이더 주 관심 구간, **1억 주 초과는 안정적**[^12]
- Humbled Trader: **float 1,000만 주 미만은 분 단위로 급변**, 예시로 **float 80만 주 종목이 하루 50~100% 급등**[^14]
- 스퀴즈 결합조건: **short interest가 float 대비 높고** + float 이 빠르게 회전 + 호재 → 숏커버 강제[^12]

### 4.2 숏스퀴즈 스크리닝 임계값

**출처**: Liberated Stock Trader[^53], LuxAlgo[^54], TradeAlgo[^72]

- **Short interest % of float > 20%** 를 "스퀴즈 영역" 진입으로 봄. **30% = 높음, 40%+ = 드묾**[^53]
- **Days to Cover (DTC) > 7** 을 시작 임계값, **10 이상**이면 전량 커버에 2주 이상 소요[^54]
- 좋은 스퀴즈 후보 4조건: (1) short % of float > 20%, (2) DTC > 5, (3) 상대적으로 **낮은 float**, (4) 촉매 존재[^53]
- 데이터 소스: **FINRA short interest**(월 2회 공시), Finviz, Fintel, Stock Rover[^53]

**신뢰도**: 임계값은 업계 관행이며 학술적 검증치가 아니다 **(통념)**. FINRA 데이터는 **월 2회 지연 공시**라 당일청산 신호로는 태생적 지연이 크다.

**구현 가능성 — C (외부 데이터 필수)**
- **float 가 없다.** 토스 `/stocks` 의 `sharesOutstanding` 은 **발행주식수**이며 내부자·락업 지분을 포함한다. 저float 종목일수록 발행주식수와 float 의 괴리가 커서 **프록시로 쓰면 위험**하다.
- short interest, DTC 도 없음 → FINRA/Finviz/Fintel 등 외부 소스 필수.
- **단**, `sharesOutstanding` + 1분봉 누적거래량으로 **"발행주식수 회전율(turnover)"** 은 계산 가능하다 → **float rotation 의 하한 근사치**로는 쓸 수 있다(실제 rotation 은 이보다 크다). 이 정도는 **B**.

## 5. Mean Reversion / Gap Fill / VWAP 회귀

### 5.1 갭 채움(Gap Fill) 확률 통계

**출처**: TradingStats.net NQ 2,791거래일(2015–2025)[^26], QuantifiedStrategies[^27], SmallCapLab[^28]

| 조건 | 당일 채움 확률 |
|---|---|
| 전체 평균 (정규장 중 언젠가) | **약 76%** [요약본 기준][^27] / 최근 6개월 S&P500 기준 **약 60%**[^27] |
| **초소형 갭 (< 0.3×ATR)** | **약 78%** (종가까지)[^26] |
| 소형 갭 | **약 42%**[^26] |
| 중형 갭 | **약 25%**[^26] |
| **대형 갭 (> 1.2×ATR)** | **약 8%**[^26] |
| 고변동성 + 대형갭 + 전일 레인지 밖 시가 동시 성립 | **약 21%**[^26] |
| 저거래량 갭 | **2일 내 85%** 채움[^26] |
| 고거래량 갭 | **5일 이상 소요 시 45%**[^26] |
| 갭다운 후 오버나잇 랠리 (희귀, 30건) | **83.3%** — 표본 극소[^26] |

**소형주 갭업 페이드율**[^28]: 중국계 상장사 424건 **64.9%**, 미국 기업 **63.7%**. 갭이 채워지는 경우 **첫 1시간 안에 압도적으로 채워짐**. 고점(HOD) 형성 시각: 중국계 **첫 1시간 내 58.8%**, 미국계 **55%**[^28]

**신뢰도 평가**:
- **ATR 대비 갭 크기가 채움확률의 결정변수**라는 결론은 여러 출처에서 일관되며 신뢰도 **상**. **이 규칙 하나만으로도 강력한 필터**가 된다.
- 다만 **개별 종목 vs 지수선물(NQ)** 결과가 섞여 있다. NQ 통계를 개별주에 그대로 적용하면 안 된다.
- "83.3%" 같은 30건짜리 표본은 **의미 없음**으로 취급.

**당일청산 규칙**: 갭 < 0.3×ATR 이면 **갭 반대방향(채움 방향) 진입, 목표 = 전일 종가, 손절 = 시가 대비 X%**, 미체결 시 LOC 청산.

**구현 가능성 — A** (전일 종가·ATR 은 일봉 캐시, 시가·현재가는 1분봉/현재가). **이 문서에서 가장 순수하게 A 등급인 방법론 중 하나다.**

### 5.2 QuantConnect "Mind the Gap" — 갭다운 인트라데이 반전

**출처**: QuantConnect 리서치 포럼[^22]

- **유니버스**: S&P 500 구성종목 중 **100일 SMA 위**
- **진입**: 시가에 전일 종가 대비 **14일 ATR의 1.2배 초과 갭다운**이면 **롱**
- **청산**: 개장 **15분 후 전량 청산**
- 개장 직후 진입, 같은 날 청산 = 완전한 당일청산 전략

**신뢰도**: QuantConnect 공식 리서치 노트로 코드가 공개되어 **재현 가능성 상**. 다만 요약본에서 **성과수치(수익률/Sharpe)를 확인하지 못했다 → 수치 미확인**.

**구현 가능성 — B**
- ATR(14), 100 SMA, 전일종가: 일봉 200개로 계산 **A**
- S&P500 구성종목: **사전 유니버스 필요 → B** (토스에 지수 구성종목 API 없음)
- 시가 = 1분봉 첫 봉. 15분 후 청산은 `MARKET` 주문으로 가능.
- **장점: 시그널 판정이 개장 시점 1회뿐이라 폴링 부하가 극히 낮다.** 500종목 시가 확인은 `/prices` 3콜(≈0.3초)로 끝난다. **폴링 REST 환경에 가장 잘 맞는 구조.**

### 5.3 VWAP 표준편차 밴드 회귀

**출처**: 커뮤니티 정리[^66][^65]

- VWAP 기준 **±1σ, ±2σ (때로 ±3σ)** 밴드. 변동성에 따라 확장/수축
- 진입: **+2σ 터치/관통 후 거부캔들(긴 꼬리 + 밴드 안쪽 종가)** → 숏. **-2σ** → 롱[^66]
- 청산: **VWAP 회귀**
- **필터 필수**: ADX 필터로 추세일(trend day) 회피. 필터 있으면 **승률 55~65%**, 없으면 **약 45%** [요약본 기준][^66]
- 검증 권고: 최소 **30세션** 신호 기록[^66]

**신뢰도**: 승률 55~65%는 **출처가 트레이딩 교육 블로그이며 백테스트 코드/표본이 공개되지 않음 → 신뢰도 하**. "필터 없으면 45%"라는 자기고백은 오히려 정직한 신호이며, **핵심 메시지(추세일에는 역추세가 죽는다)는 신뢰할 만하다.**

**구현 가능성 — A**. VWAP·σ밴드·ADX 전부 1분봉으로 계산. shortlist 한정.

### 5.4 RSI(2) 평균회귀 — **당일청산에는 부적합**

**출처**: QuantifiedStrategies[^58]

- Larry Connors RSI(2) 전략. SPY 2000–2024 **387거래, 승률 73%**, 평균이익 +1.8% / 평균손실 -2.1%, **Profit Factor 1.65**, 연 9.4%, 시장노출 22% [요약본 기준][^58]
- S&P500 전 구성종목 적용 시 **총 승률 69%**[^58]

**신뢰도 및 적합성 평가**: 수치는 구체적이나 **이 전략은 며칠~수주 보유하는 스윙 전략**이다. 당일청산에 그대로 쓰면 완전히 다른 전략이 된다. 인트라데이 변형(30분봉 2기간 RSI < 5 / > 95)이 언급되나 **성과수치 미확인**. → **당일청산 후보로는 우선순위 하.**

**구현 가능성 — A** (계산은 쉬움). 문제는 유효성이지 구현이 아니다.

## 6. Opening Range Breakout (ORB)

가장 학술적 근거가 두텁고, 토스 API 제약과의 궁합도 가장 좋은 카테고리다.

### 6.1 Zarattini & Aziz (2023) — "Can Day Trading Really Be Profitable?" (QQQ 5분 ORB)

**출처**: SSRN 4416622[^19], CXO Advisory 리뷰, Concretum Group[^76]

**규칙 (요약본에서 확인)**[^19]
- 대상 **QQQ** (레버리지 버전은 **TQQQ**)
- 첫 **5분봉**이 상승(하락) 마감이면 **두 번째 5분 구간 시작에 매수(매도)**
- 시가와 종가가 거의 같으면 **미진입**
- 손절: 첫 5분봉의 **저가(롱) / 고가(숏)**
- 목표: **진입가–손절가 차이의 10배 (10R)**
- 미달 시 **장 마감에 청산** (완전한 당일청산)

**성과 (2016–2023)**[^19]
- ORB 포트폴리오 **+1,484%** vs QQQ 매수후보유 **+169%**
- **연환산 알파 33% (수수료 차감 후)**, TQQQ 사용 시 **연환산 알파 48%**

**신뢰도 평가**
- **긍정**: SSRN 공개 논문, 저자 중 1인이 학계(Andrea Barbon, USI). 규칙이 완전히 기계적이라 재현 가능. 수수료 차감을 명시.
- **부정/주의**: (1) 저자 Andrew Aziz 는 **Bear Bull Traders 창업자**로 **트레이딩 교육 상업적 이해관계**가 있다. (2) 2016–2023 은 **거대한 상승장 + 2020/2022 고변동성 구간**에 편중되어 **레짐 의존 가능성**이 크다. (3) **10R 목표**는 사실상 "장 마감까지 홀드"와 유사해, 성과가 **소수의 대박일(fat tail)에 의존**할 가능성이 높다 → 이 경우 실현 승률은 낮고 최대 연속손실이 길다. (4) TQQQ(3배 레버리지) 성과를 함께 제시하는 것은 **성과 과장 프레이밍**이다.
- **종합 신뢰도: 중상.** 다만 **반드시 독립 재현 필요**하고, 승률이 아닌 **손익분포**를 확인해야 한다.

**구현 가능성 — A**. QQQ 1종목 1분봉만 있으면 된다. 5분봉은 1분봉 5개 리샘플. 손절은 폴링 감시, 마감청산은 LOC. **폴링 부하 사실상 0.**

### 6.2 Zarattini, Barbon & Aziz (2024) — "A Profitable Day Trading Strategy for the U.S. Equity Market" (Stocks in Play ORB)

**출처**: SSRN 4729284[^18], QuantConnect 리서치[^21], QuantifiedStrategies[^23]

**유니버스 자격조건 (확인됨)**[^23]
- 시가 **> $5**
- **직전 14일 평균 거래량 ≥ 1,000,000주/일**
- **직전 14일 ATR > $0.50**

**핵심 필터 (확인됨)**[^23]
- **개장 첫 5분 Relative Volume(RV) > 100%** (= 해당 시각 평상시 대비 2배 이상, 정의는 원문 확인 필요)
- **매일 RV 상위 20종목만** 매매

**진입/리스크 (확인됨)**[^18]
- **5분 ORB** 기준
- **손절: 진입가로부터 14일 ATR의 10% 거리** [요약본 기준 — 원문 재확인 권장]
- 포지션 사이징: 손절 도달 시 손실이 **투입자본의 1%** 를 넘지 않도록, **최대 레버리지 4배** 제약

**성과 (2016.1.1–2023.12.31, 7,000개 이상 미국주식)**[^18][^23]
- **총수익 +1,637%**, **연환산 IRR 41.6%**, **Sharpe 2.81**, **연환산 알파 36%**, 베타 거의 0
- 비교: S&P500 패시브 **+198%**
- **필터 없는 ORB 는 7년간 총 +29%에 불과** → **RV 필터가 성과의 거의 전부**[^23]
- $25,000 → 약 $435,000 (RV 필터 적용) vs 약 $75,000 (S&P500 패시브)[^18]

**신뢰도 평가**
- **긍정**: 표본이 7,000종목 × 8년으로 크다. **"필터 없으면 +29%"라는 대조군을 명시**한 점은 방법론적으로 매우 좋다 — 저자들이 엣지의 출처를 정직하게 지목했다. Swiss Finance Institute 워킹페이퍼 번호(N°24-98) 부여.
- **부정/주의**: (1) **Sharpe 2.81 + 연 41.6%는 리테일 실행 환경에서 재현 불가능에 가깝다.** 매일 상위 20종목을 **개장 후 5분 시점에 즉시 선별하고 진입**해야 하는데, 이는 **실시간 전체시장 스캐닝 + 저지연 체결**을 전제한다. (2) **최대 4배 레버리지**를 쓴 수치다. (3) **슬리피지 가정**이 요약본에서 확인되지 않았다. 하루 20종목 × 8년이면 회전율이 극단적으로 높아 **비용 가정이 성과를 좌우**한다. (4) 저자의 상업적 이해관계는 §6.1과 동일.
- **종합 신뢰도: 중상 (논문으로서), 하 (리테일 실현가능성으로서).**

**구현 가능성 — B, 단 심각한 실행 병목**
| 요소 | 등급 | 근거 |
|---|---|---|
| 시가 > $5, ATR > $0.50, ADV > 100만 | **B** | 일봉 캐시로 계산. 유니버스 사전 확정 필요 |
| **첫 5분 RV 계산** | **B** | 1분봉 5개 필요 = **1종목 1콜**. 5 TPS |
| **"매일 RV 상위 20" 랭킹** | **문제 지점** | 랭킹을 만들려면 **후보 전체의 첫 5분 거래량**이 필요. 후보 1,000종목이면 **200초** → **개장 5분 시점에 랭킹 완성 불가**. 후보를 **150종목 이하로 줄여야 30초 내 랭킹 가능** |

> **2번 에이전트에게**: 이 전략의 성과는 "**전체 시장에서 상위 20을 뽑는 것**"에서 나온다. 유니버스를 150종목으로 줄이면 그 상위 20은 전혀 다른 집합이다. 이 축소가 성과를 얼마나 깎는지는 **반드시 백테스트로 확인**해야 하며, 그 전에는 성과를 인용하지 말 것.

### 6.3 ORB 타임프레임 비교 (5분 vs 15분 vs 30분)

**출처**: ORB Setups 자체 백테스트[^24], QuantifiedStrategies[^25], tosindicators[^50]

| 출처 | 표본 | 결과 |
|---|---|---|
| ORB Setups[^24] | **614종목 / 1,178,668 트레이드** | 5분 **53.78%**, 15분 **50.97%**, 30분 **49.38%** 승률 |
| ORB Setups (gap and go 문맥)[^39] | — | 평균 승률 5분 **52.2%**, 15분 **52.5%**, 30분 **52.9%** (30분이 최고) |
| 일반 인용[^24] | S&P500 10년 | 15분 ORB **승률 56%, 평균 R:R 1.8:1** [요약본 기준] |
| tosindicators SPY 백테스트[^50] | 2016.1~2023.2 | 매수후보유 SPY **Sharpe 0.836** vs ORB **Sharpe 2.396**, **베타 -0.042**. 25개 파라미터 조합 중 **17개(68%)가 벤치마크보다 높은 Sharpe** |

**정성적 특성**[^24]
- **5분**: 신호 빈도 최다, 수익 최대이나 **거짓돌파 최다**. "레인지가 짧을수록 성과가 좋다"는 선형관계가 관찰됨. 15분 대비 수익 거의 2배, MDD 절반 수준
- **15분**: 무난한 표준 선택
- **30분**: 신호 최소, 확신도 최고, 거짓돌파 최소, 추세일에 강함

**신뢰도 평가**: **동일 출처(ORB Setups) 내에서도 승률 수치가 상충**한다(5분 53.78% vs 52.2%, 30분 49.38% vs 52.9%). 목표/손절 파라미터가 다른 두 실험을 병렬 인용한 것으로 보인다. **→ 승률 절대값은 신뢰하지 말고, "타임프레임 간 승률 차이는 1~4%p 수준으로 크지 않다"는 정성적 결론만 채택하라.** 승률보다 **R:R 과 파라미터 민감도**가 결정적이다. "25개 조합 중 17개가 벤치마크 초과"[^50]는 **파라미터 강건성(robustness)** 증거로서 승률보다 유용한 정보다.

**구현 가능성 — A**. 1분봉 리샘플로 5/15/30분 OR 모두 계산.

## 7. 뉴스/촉매 기반

**출처**: Benzinga Pro[^36][^37], SMB[^15], Warrior[^3]

- 촉매 유형: **실적, FDA 승인/PDUFA 일자/임상 마일스톤, M&A, 애널리스트 등급, 8-K, 행동주의 투자자**[^36][^37]

**신뢰도**: "5~15분 선행"은 **벤더 자체 마케팅 주장**이며 독립검증 없음 → 신뢰도 하. 반면 "촉매 유무가 갭 지속을 가른다"는 명제는 여러 출처에서 일관 → 신뢰도 중상, 단 **정량화된 수치는 확인 못 함**.

**구현 가능성 — C (외부 데이터 필수, 예외 없음)**
- 토스 API 에 **뉴스·실적일정·애널리스트 등급이 전무**하다.
- 필요 외부 데이터: 실시간 뉴스 API(Benzinga/Polygon/Finnhub 등), SEC EDGAR 8-K 피드, 실적 캘린더.
- **비용·지연·법적 이용약관**이 모두 걸리는 영역. 리테일 자동매매의 현실적 1차 범위에서는 **제외 권장**.
- **단, 완전 제외 대신 "촉매 프록시"는 가능하다**: 뉴스 없이도 **갭% + RVOL 급등**이 사실상 "무언가 일어났다"의 관측 가능한 그림자다. Zarattini 논문의 "Stocks in Play" 정의가 정확히 이 접근(뉴스 대신 RV 로 대리)이며, **뉴스 API 없이도 작동한다**는 점이 이 논문의 실무적 가치다.

## 9. 기술적 필터

### 9.1 ATR / ATR% / ADR%

**출처**: Trade Ideas ATR 문서[^44], TradingView ADR%/ATR% 계산법[^45]

- **ATR**: 갭 포함, 손절폭 산정에 적합. **ADR(Average Daily Range)**: 고가–저가만, 갭 미포함, 인트라데이 기대폭 산정에 적합[^45]
- **ATR% (= ATR / 주가)** 는 **가격대가 다른 종목 간 변동성 비교**에 필수. "$10 주식의 ATR $1 과 $100 주식의 ATR $1 은 전혀 다르다"[^44]
- 스캐너에서 min/max 를 설정해 범위 밖 종목 자동 배제[^44]

**구현 가능성 — A/B**. 일봉 200개로 ATR(14), ADR, ATR% 전부 계산.

### 9.2 VWAP

- 인트라데이 추세 필터: **VWAP 기울기 상승 = 롱만, 하락 = 숏만, 평탄 = 관망**[^65]
- "VWAP 위 유지 + 거래량 = 롱사이드 추세일"[^65]
- "종목이 VWAP 아래면 롱 포지션을 가질 이유가 없다 — 숏이거나 현금"[^67]
- 4대 셋업: reclaim / first bounce / break-and-hold / failed reclaim short[^65]
- VWAP 은 매일 리셋되는 인트라데이 지표. 1분/5분/15분봉에서 사용[^65]

**신뢰도**: 규칙은 명확하나 **정량 검증치 없음 (통념)**.
**구현 가능성 — A**. 1분봉 (typical price × volume) 누적으로 정확히 계산 가능.

### 9.3 EMA 배열 / 볼린저 / RSI

- **9 EMA**: 모멘텀 트레일링 스톱 기준선. 9 EMA 이탈 = 약세[^3][^14]
- **9 EMA / 21 EMA 크로스**: 진입 신호로 사용. 강세 진입은 EMA 가 VWAP 위로 교차할 때[^65]
- **볼린저 스퀴즈**[^57]: 표준 **20기간 / 2σ**. 인트라데이용 타이트 세팅은 **10기간 / 1.5σ**. 진입은 **밴드 밖 종가 확정 캔들**(터치만으로는 부족). **거래량 확인 필수 — 20일 평균 대비 +50% 이상 스파이크가 없으면 페이크**. 손절은 **20 SMA**(가격이 밴드 안으로 복귀하면 실패 확정). 데이트레이더는 5분~1시간봉 권장[^57]
- **Oliver Velez "Narrow State"**[^Velez]: **20 SMA 와 200 SMA 가 1.2~1.5% 이내로 수렴**하면 압축 상태 → 폭발적 돌파 선행. 도구는 20/200 SMA + 색상 거래량 + **5기간 CCI**[^Velez]. Velez 는 **대형 유동주(FB, AAPL, SBUX, HD 등)** 만 짧은 관심종목으로 운용하며, 급등 추격 대신 **지지선 되돌림 진입**[^Velez]

**신뢰도**: 전부 **정량 검증치 없는 관행 (통념)**. 볼린저 스퀴즈의 "거래량 +50%" 조건은 구체적이나 근거 출처가 교육 블로그.

**구현 가능성 — A**. 전부 1분봉/일봉으로 계산 가능.

## 10. 통계·퀀트 팩터

### 10.1 Market Intraday Momentum (Gao, Han, Li & Zhou) — **학술적 근거 최상**

**출처**: SSRN 2440866 / 2552752[^16], Journal of Financial Economics 2018[^17], Alpha Architect 리뷰

- **데이터**: SPY(S&P500 ETF) 고빈도 데이터 **1993–2013**[^16]
- **발견**: **전일 종가부터 측정한 첫 30분 수익률이 마지막 30분 수익률을 양(+)의 방향으로 예측**한다[^16]
- **통계**: 스케일된 기울기 **6.94**, **1% 유의수준**, **R² = 1.6%**[^16]
- **강화 조건**: **변동성이 높은 날, 거래량이 많은 날, 경기침체기, 주요 거시지표 발표일에 예측력이 강해진다**[^16]
- **일반화**: 가장 활발히 거래되는 **국내외 ETF 10종에서도 인트라데이 모멘텀이 존재**[^16]
- **이론적 설명**: Bogousslavsky 의 **비빈번 리밸런싱(infrequent rebalancing)** 모델, 그리고 **장 마감 근처 늦게 정보를 얻은 거래(late-informed news trading)** 모델과 정합[^16]

**신뢰도 평가: 상.** JFE 게재 논문, 20년 표본, 명확한 통계량, 이론적 메커니즘 제시. **다만 R² = 1.6% 는 매우 낮다** — 예측력은 통계적으로는 확실하지만 경제적 크기는 작다. 거래비용이 이 엣지를 쉽게 잡아먹을 수 있다는 뜻이다. 또한 **2013년까지의 표본**이라 이후 알파 소멸(alpha decay) 가능성을 반드시 확인해야 한다.

**구현 가능성 — A (이 문서 전체에서 가장 깨끗한 A)**
- 필요한 것: **SPY 1종목의 1분봉과 전일 종가.** 그게 전부다.
- 판정 시점이 **하루 2회(개장 30분 후, 마감 30분 전)** 뿐이라 폴링 부하가 사실상 0.
- 청산은 **장 마감 = LOC 주문**으로 완전히 확정적.
- 유니버스 문제, float 문제, 뉴스 문제, 스크리너 부재 문제 **전부 우회**한다.

### 10.2 Zarattini, Aziz & Barbon (2024) — "Beat the Market: An Effective Intraday Momentum Strategy for SPY"

**출처**: SSRN 4824172[^20], Concretum Group[^76], TradingView "Concretum Bands"[^40], QuantifiedStrategies[^41]

**규칙 — Noise Area (확인됨)**[^40][^76]
- **시각 HH:MM 의 밴드 = 당일 시가 ± (최근 n일간 시가~HH:MM 절대이동폭 평균)**. **오버나잇 갭 보정** 포함
- 논문 기본 파라미터: **lookback n = 14일, 변동성 배수 = 1**[^40]
- 밴드 **안**이면 노이즈로 보고 **미진입**. 밴드 **밖으로 이탈**하면 수급 불균형 신호 → **추세 방향 진입**
- 학술 문헌이 마지막 30분에만 거래하는 것과 달리, **불균형 징후가 나타나는 즉시 진입**[^41]
- **30분마다** 추세 방향을 재확인하여 과매매·극단진입 방지[^76]
- **트레일링 스톱: 밴드 자체 + 당일 VWAP**[^76]

**성과 (2007–2024 초)**[^20][^41]
- **총수익 +1,985% (비용 차감 후)**, **연환산 19.6%**, **Sharpe 1.33**
- 비교: SPY 매수후보유 **Sharpe 0.45**
- **베타가 0보다 약간 낮음** → 시장과 거의 무상관

**신뢰도 평가: 중상~상.**
- **긍정**: 17년 표본으로 §10.1보다 최신까지 커버. **비용 차감 명시**. Sharpe 1.33은 §6.2의 2.81보다 훨씬 현실적인 크기라 오히려 신뢰가 간다. 지표가 **TradingView 에 공개 구현**되어 있어 재현 검증이 쉽다[^40]. Swiss Finance Institute 워킹페이퍼(N°24-97).
- **부정/주의**: 저자의 상업적 이해관계(§6.1과 동일). 2007–2024는 **저금리 + 장기 강세장** 편중. 30분 간격 재평가라도 **트레일링 스톱이 밴드/VWAP 이면 인트라데이 감시가 필요**하다.

**구현 가능성 — A**
- SPY 1종목의 **1분봉만** 필요. 밴드 계산에 **14일 × 390분 = 5,460봉** → `count=200` 기준 **28콜**, 5 TPS 로 **6초**. 매일 2콜씩 증분 갱신하면 사실상 무비용.
- 30분 간격 재평가 → 폴링 부하 극소.
- 트레일링 스톱은 `/prices` 폴링(초당 10회 가능, 1종목이므로 여유 충분)으로 감시.
- **토스 API 제약을 거의 하나도 건드리지 않는다.**

### 10.3 오버나잇 vs 인트라데이 수익 분해 (Lou, Polk & Skouras, JFE 2019)

**출처**: "A Tug of War: Overnight Versus Intraday Expected Returns"[^29], Alpha Architect[^30]

- 14개 트레이딩 전략을 분석한 결과, **수익이 전적으로 오버나잇에서 나오거나 전적으로 인트라데이에서 나오며, 두 구간의 부호가 통상 반대**다[^29]
- **모멘텀 전략의 초과수익은 거의 전부 오버나잇**에서 발생. 반면 **다른 전략들(value, profitability, investment, market beta, idiosyncratic vol, equity issuance, discretionary accruals, share turnover)의 초과수익은 주로 인트라데이**에서 발생하며, 이들 모두 **부호가 반대인 유의한 오버나잇 프리미엄**을 가진다[^29]
- 광범위한 관련 연구: **미국 시장 장기 수익의 거의 전부가 오버나잇에 귀속**되고 **평균 인트라데이 수익은 음(-) 또는 0에 가깝다**[^30]

**신뢰도: 상** (JFE 게재, 11.6M+ 가격관측 계열 연구들과 일관).

**당일청산 전략에 대한 함의 — 매우 중요**
> **당일청산 전략은 정의상 "인트라데이 구간의 수익만" 취한다. 그런데 미국주식의 인트라데이 평균수익은 0 또는 음수다.**
> → **롱 온리 당일청산 전략은 구조적 역풍(structural headwind)을 안고 시작한다.**
> → 즉, 당일청산 전략은 **"시장 베타로 버는 것"이 불가능**하고 **순수하게 타이밍 알파로만** 벌어야 한다. 이것이 §0.3의 참담한 기저율을 설명하는 구조적 이유다.
> → 반대로, **숏 사이드를 포함하거나 시장중립적으로 설계하면** 이 역풍이 오히려 순풍이 될 수 있다. 다만 토스 API 는 미국주식 공매도를 지원하지 않는 것으로 보이므로(스펙에 숏 관련 필드 없음) **롱 온리 제약이 걸린다.**

**구현 가능성 — A** (팩터로서의 계산은 쉬움). 함의는 **전략 설계 전제**로 반영할 것.

### 10.4 시간대 효과 (Intraday U-shape)

**출처**: Örebro University 워킹페이퍼(2025)[^56], Gao et al.[^16], arXiv 인트라데이 패턴 연구[^71]

- **거래량·변동성의 U자 패턴**: 개장에 무겁고, 점심에 죽고, 마감에 다시 무겁다. SPY 분단위 데이터 **2008–2021** 로 일관 확인[^56]
- 수익률 변동성 실측: **09:35 약 0.08% 최고 → 13:05 약 0.03% 최저 → 16:00 약 0.05%로 재상승**. 09:30 시점은 약 0.07%[^56]
- **새 정보의 소화에 약 30분** 소요 — 첫 30분의 높은 거래량/변동성이 근거. 이후 마지막 30분까지 냉각[^56]
- **첫 30분과 마감에 평균적으로 유의한 양(+)의 수익**[^56]
- 실무 함의: **11:30~13:30 ET 는 거래량·변동성이 크게 하락해 신호 품질이 떨어진다**[^56]

**신뢰도: 상.** 학술 + 실무 관측이 일치.
**구현 가능성 — A** (시각 기반 필터, 데이터 불필요). **가장 값싸고 확실한 개선 수단.**

### 10.5 요일 효과

**출처**: Birru, "Day of the Week and the Cross-Section of Returns"[^55], Alpha Architect[^30]

- 롱숏 아노말리 수익이 요일과 강하게 연관. **투기적 다리(speculative leg)가 숏일 때 월요일 수익 최고**, 금요일은 정반대 패턴[^55]
- **월요일/금요일 변동은 전부 인트라데이에서 발생.** 특히 **월요일 반전은 월요일 오후에서 발생**하며, 월요일 오전은 예측력이 없다[^55]
- 월요일(금요일) 하루가 조사대상 아노말리들의 **월간 수익의 100% 이상**을 설명[^55]
- 행동적 설명: 심리학 문헌의 **목→금 기분 상승, 월 기분 하락**과 정합[^55]
- **소형주·비유동주에서 캘린더 아노말리가 더 강하고, 대형 유동주에서는 약하거나 없다**[^55]

**신뢰도: 중상.** 학술 논문이지만 캘린더 아노말리는 **데이터 스누핑 우려**가 상시 존재하고 발표 후 소멸 사례가 많다.
**구현 가능성 — A** (요일은 무료). **단, 단독 전략이 아니라 보조 필터로만 쓸 것.**

### 10.6 갭 아노말리 / 인트라데이 반전 (학술)

**출처**: 갭 아노말리 및 인트라데이 반전 관련 연구 요약[^71]

- 오버나잇·인트라데이 **기업 수준 수익 연속성**과 이를 상쇄하는 **기간간 반전(cross-period reversal)** 이 수년간 지속[^71]
- **정확히 거래일 배수인 30분 간격에서 수익 연속성 패턴**이 나타나며 최소 **40거래일** 지속[^71]
- 미국 지수선물 15년 연구: **유의한 인트라데이 가격 반전**이 발생하며, **큰 양(+)의 시가 변동에서 과잉반응이 더 뚜렷**[^71]
- **갭 크기와 반전 강도 간 유의한 상관** — 큰 갭일수록 되돌림도 크다[^71]
- 횡단면: **밤→낮 반전이 잦은 종목이 횡단면에서 더 높은 수익**. 주간 차익거래자가 야간 낙관적 노이즈 트레이더의 영향을 상쇄한다는 가설[^71]

**신뢰도: 중.** 요약 수준까지만 확인했고 표본·유의수준을 대조하지 못했다. **수치 인용 금지, 방향성만 참고.**
**구현 가능성 — A/B.**

## 12. 폴링 기반 리테일 알고의 현실성 — 작동하는 전략 vs 작동 안 하는 전략

### 12.1 커뮤니티가 말하는 것

- r/algotrading: "**알고트레이딩은 전략 5%, 에러핸들링 95%**". 백테스트에서 수익났던 전략이 "**라이브 시장의 슬리피지에 파괴됐다**"는 보고가 반복됨[^73]
- 유동성 문제: 많은 종목/옵션이 **얕은 호가 깊이와 넓은 스프레드**를 가져 **예상보다 나쁜 가격에 체결**된다[^73]
- 운영 리스크: 기술 장애, 연결 문제, **API 중단, 브로커 다운타임, 거래소 장애, 주문 거부** 모두 진입/청산 실패로 이어진다[^73]
- 참조 지연: Alpaca 등 리테일 REST/WebSocket 플랫폼의 실측 평균 지연 사례로 **약 100ms** 가 인용됨[^73]
- 결론적 시사: **REST 기반 시스템은 태생적 지연 한계가 있어 HFT 인프라와 경쟁 불가**. 따라서 **현실적 비용·슬리피지를 넣은 백테스트가 필수**[^73]

### 12.2 토스 API 폴링 환경의 실제 지연 예산

| 구간 | 지연 |
|---|---|
| 1분봉 확정 대기 | **최대 60초** (봉이 닫혀야 값이 확정) |
| 1분봉 폴링 순번 대기 (shortlist 50종목, 5 TPS) | **최대 10초** |
| 현재가 폴링 순번 대기 (200종목/콜, 10 TPS) | **1초 미만** |
| API 왕복 (한국↔서버, HTTPS) | **수십~수백 ms** |
| 주문 전송 → 체결 | **미확인** (브로커 라우팅 의존) |
| **합계 (1분봉 기반 신호)** | **약 60~75초** |
| **합계 (현재가 기반 신호)** | **약 1~3초** |

### 12.3 판정: 폴링 REST 로 작동하는가?

| 전략 유형 | 판정 | 이유 |
|---|---|---|
| **하루 1~2회 판정 (Market Intraday Momentum, Mind the Gap)** | **작동 (D 위험 없음)** | 판정 시점이 고정되어 있고 60초 지연이 신호 대비 무시 가능 |
| **30분 간격 재평가 (Beat the Market / Concretum)** | **작동** | 30분 주기에 60초 지연은 3% 수준 |
| **5분/15분/30분 ORB** | **작동 (5분은 경계)** | 5분 OR 돌파는 60초 지연이 신호의 20% → 진입가 열화. **15분/30분 ORB 가 폴링에 훨씬 적합** |
| **갭 스캐닝 (현재가 기반)** | **작동** | `/prices` 200종목/콜, 1초 미만 |
| **RVOL 실시간 랭킹 (전체시장)** | **작동 안 함** | 1분봉이 1종목 1콜이라 1,000종목 랭킹에 200초. **개장 5분 시점 전수 랭킹 불가** |
| **HOD 돌파 즉시 진입 / 1분봉 bull flag** | **부분 작동 (열화)** | 1분 지연 진입 → 저float 급등주에서는 진입가가 크게 밀린다 |
| **호가창 기반 스캘핑 / 할트 재개 플레이 / 뉴스 반응 매매** | **작동 안 함 (D)** | 초 단위 반응 필요. WebSocket 부재가 치명적 |
| **저float 소형주 모멘텀 전반** | **작동 안 함 권장** | 지연 + 슬리피지 20~100bp[^61] + 할트 리스크[^33] 삼중고. **리테일 폴링 알고가 가장 지면 안 되는 싸움** |

> **핵심 결론**: 토스 폴링 환경에서는 **"빠른 종목을 빨리 잡는" 전략 전부가 구조적으로 불리**하다.
> 반대로 **"판정 시점이 드물고, 대상이 유동성 최상위이며, 청산이 마감으로 확정되는" 전략**이 압도적으로 유리하다.

### 12.4 백테스트에 넣어야 할 비용 가정

| 항목 | 권장 가정 | 근거 |
|---|---|---|
| 대형주/ETF 스프레드 | **1~5bp** | AAPL급 1bp 미만[^61] |
| 소형주 스프레드 | **20~100bp** | [^61] |
| 슬리피지 총효과 (소형주) | **30bp** 를 표준 가정으로 | [^61] |
| 주문쏠림 시 | **30bp 초과** | [^61] |
| **1분 지연으로 인한 진입가 열화** | **별도로 반영 필수** — 신호봉 종가가 아닌 **다음 봉 시가**로 체결 가정 | §12.2 |
| 환전 비용 | 토스 `/exchange-rate` 및 `/commissions` 로 실측 | API 제공 |
| 왕복 최소 비용 (보수적, 대형주) | **왕복 10~20bp** 를 하한으로 놓고 시작 **(통념 + [^61] 기반)** | — |

> 참고: Barber & Odean 의 대만 데이트레이더 **일평균 -23.9bp**[^46] 는 대략 "왕복비용 수준의 손실"과 일치한다. **즉, 평균적 데이트레이더의 손실 = 거래비용**이다. 전략이 비용을 이기지 못하면 정확히 이 결과가 나온다.

## 14. 결론 — 가장 유망한 상위 5개 방법론

선정 기준: (1) **토스 API 단독 구현 가능성(A 등급 우선)**, (2) **폴링 지연에 강건**, (3) **근거 강도**, (4) **당일청산 확정성(LOC 청산과의 궁합)**.

### 1위. Market Intraday Momentum — 첫 30분이 마지막 30분을 예측 (Gao, Han, Li & Zhou)[^16][^17]
- **근거 강도가 이 문서에서 유일하게 "상"이다.** Journal of Financial Economics 게재, SPY 1993–2013, 기울기 6.94, 1% 유의, R²=1.6%. 이론적 메커니즘(비빈번 리밸런싱, 늦은 정보거래)까지 제시되어 데이터 스누핑 가능성이 낮다.
- **구현 등급 A, 그것도 가장 순수한 A.** SPY 1종목의 1분봉과 전일 종가만 필요하다. float·뉴스·스크리너·프리마켓 데이터 부재라는 토스 API 의 4대 제약을 **전부 우회**한다.
- **폴링 지연에 완전히 면역이다.** 판정이 하루 2회(개장 30분 후, 마감 30분 전)뿐이라 60초 지연이 무의미하고, 청산이 곧 장 마감이라 **LIMIT+CLS(LOC)로 당일청산이 구조적으로 보장**된다. 단, R²=1.6%는 경제적 크기가 작다는 뜻이므로 **거래비용을 넣은 재검증과 2013년 이후 알파 소멸 확인이 필수**다.

### 2위. Beat the Market / Concretum Bands — SPY 인트라데이 모멘텀 (Zarattini, Aziz & Barbon)[^20][^40][^76]
- **1위의 실전 확장판이며 표본이 2007–2024로 더 최신이다.** 연 19.6%, Sharpe 1.33은 같은 저자군의 다른 논문(Sharpe 2.81)보다 훨씬 겸손한 수치라 오히려 신뢰가 간다. 비용 차감을 명시했고, 베타가 0 근처라 분산효과도 있다.
- **구현 등급 A.** 밴드 계산에 SPY 1분봉 14일치(약 5,460봉 = 28콜, 6초)만 필요하고 이후 매일 2콜씩 증분 갱신하면 된다. TradingView 에 지표가 공개 구현되어 있어 **재현 검증 비용이 극히 낮다**[^40].
- **30분 간격 재평가 구조가 폴링 REST 와 궁합이 완벽하다.** 트레일링 스톱이 밴드+VWAP 이라 손절 감시가 필요하지만, 대상이 SPY 1종목이므로 `/prices` 를 초당 여러 번 폴링해도 rate limit 여유가 넘친다. 저자의 상업적 이해관계와 강세장 편중은 감안해야 한다.

### 3위. ORB — 15분/30분 Opening Range Breakout (유동성 최상위 대상)[^19][^24][^50]
- **당일청산 전략 중 학술·실무 양쪽에서 가장 두껍게 검증된 계열이다.** SPY 대상 백테스트에서 Sharpe 2.396 vs 매수후보유 0.836, 그리고 **25개 파라미터 조합 중 17개(68%)가 벤치마크를 초과**했다는 점이 승률 수치보다 훨씬 중요하다 — 이는 **파라미터 강건성**의 증거다.
- **구현 등급 A.** 1분봉 리샘플로 5/15/30분 OR 을 전부 만들 수 있고, 손절은 폴링 감시, 마감 미달 시 LOC 청산으로 당일청산이 확정된다.
- **5분이 아니라 15분/30분을 선택해야 한다.** 5분 OR 은 60초 폴링 지연이 신호의 20%를 잡아먹지만 15/30분은 3~7%에 그친다. 출처 간 승률 수치가 상충(5분 53.78% vs 52.2%)하므로 **승률 절대값은 인용하지 말고 자체 백테스트로 확정**해야 한다.

### 4위. Gap Fill / 갭 페이드 — ATR 정규화 갭 크기 기반[^26][^27][^28]
- **"갭 크기를 ATR 로 정규화하면 당일 채움확률이 78% → 42% → 25% → 8%로 단조 감소"라는 결과가 서로 다른 출처에서 일관되게 나타난다.** 이 단조성 자체가 신뢰의 근거이고, 필터 하나로 기대값을 크게 가를 수 있다는 점에서 실용성이 매우 높다.
- **구현 등급 A.** 전일 종가와 ATR(14)은 일봉 캐시로, 시가와 현재가는 1분봉/`/prices` 로 계산된다. **`/prices` 200종목/콜(10 TPS)로 전 유니버스 갭% 스캔이 1초 미만에 끝나므로**, 토스 API 의 "스크리너 부재" 제약을 정면으로 우회하는 유일한 대량 스캐닝 방식이다.
- **판정 시점이 개장 직후 1회로 압축되어 폴링 부하가 최소다.** 다만 NQ 지수선물 통계와 개별주 통계가 섞여 인용되고 있으므로 **개별주 대상 자체 재현이 필수**이며, 소형주 페이드율(63.7~64.9%)은 §12의 슬리피지·할트 리스크 때문에 그대로 취하면 안 된다.

### 5위. Mind the Gap — ATR 정규화 갭다운 인트라데이 반전 (QuantConnect)[^22]
- **규칙이 완전히 기계적이고 모호성이 없다.** "S&P500 ∩ 100일 SMA 위" 유니버스에서 "시가 갭다운 > 1.2×ATR(14)이면 롱, 개장 15분 후 전량 청산" — 파라미터가 3개뿐이라 과최적화 여지가 작고 QuantConnect 에 코드가 공개되어 재현 가능하다.
- **구현 등급 B이지만 폴링 환경 적합성은 이 문서 최고 수준이다.** 판정이 개장 시점 **단 1회**이고, S&P500 500종목의 시가 확인은 `/prices` 3콜(약 0.3초)로 끝난다. 보유시간이 15분이라 오버나잇·마감 리스크가 전혀 없고 자본 회전이 빠르다.
- **B 등급인 이유는 오직 "S&P500 구성종목 리스트"를 외부에서 주입해야 하기 때문**이며, 이는 월 1회 갱신하면 되는 정적 데이터라 실질 부담이 거의 없다. **다만 요약본에서 성과 수치(수익률/Sharpe)를 확인하지 못했다** — 채택 전 반드시 자체 백테스트로 기대값을 먼저 확인해야 한다.

### 상위 5개에서 탈락한 것과 그 이유
- **Gap & Go / Low Float 모멘텀 (Warrior 계열)**: float·뉴스·프리마켓 거래량이 **전부 토스 API 에 없고(C 등급)**, 1분 폴링 지연 + 소형주 슬리피지 20~100bp + LULD 할트가 겹쳐 **리테일 폴링 알고가 가장 이기기 힘든 싸움**이다. 게다가 대표 채널이 **FTC 에 허위 수익주장으로 제소되어 $3M 을 합의**했다[^47].
- **ORB Stocks in Play (Sharpe 2.81)**: 성과가 **"전체 시장에서 RV 상위 20을 뽑는 것"에서 나오는데**, 1분봉이 1종목 1콜이라 개장 5분 시점의 전수 랭킹이 물리적으로 불가능하다. 유니버스를 축소하면 **다른 전략이 되므로 논문 성과를 인용하면 안 된다.**

### 2번 에이전트에게 남기는 3가지 경고
1. **구조적 역풍**: 미국주식의 **인트라데이 평균수익은 0 또는 음수**이고 장기수익의 거의 전부가 오버나잇에서 발생한다[^29][^30]. 롱 온리 당일청산은 시장 베타로 벌 수 없고 **순수 타이밍 알파로만** 벌어야 한다.
2. **최우선 PoC 검증 항목**: (a) `/candles?interval=1m` 에 **프리마켓 봉이 포함되는가** — 갭 계열 전략 다수의 생사가 걸림. (b) `securityType` 이 **ADR/ETF 를 구분하는가**. (c) `adjusted=true/false` 비교로 **분할·병합 탐지가 가능한가**. (d) LOC(`LIMIT`+`CLS`) 주문의 **실제 체결률**.
3. **비용을 먼저 넣고 백테스트하라**: 대만 데이트레이더의 일평균 손실 **-23.9bp**[^46] 는 사실상 왕복 거래비용과 같다. 비용 없는 백테스트는 무조건 통과하고 라이브에서 정확히 이 숫자만큼 잃는다.
