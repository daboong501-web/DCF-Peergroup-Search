## 2. 확정 시나리오

### 2.1 하루 흐름

```
09:00 ─────────────────────────────────────────────────── 15:30
  │◄── 개장레인지 15분 ──►│                          │      │
  │   고가/저가만 기록      │                          │      │
  │   진입 금지 ✗          │                          │      │
                          │◄── 진입 가능 ──►│  점심  │◄진입►│
                          09:15          11:30    13:30  14:50
                                                                15:15 강제청산
```

| 구간 | 시각 | 동작 |
|---|---|---|
| 개장레인지 | 09:00~09:15 | 고가/저가만 기록. **진입 금지** — 스프레드가 벌어지는 구간에서 들어가면 비용 우위를 스스로 날린다 |
| 1차 진입존 | 09:15~11:30 | 돌파 → 눌림목 지정가 진입 |
| 점심 공백 | 11:30~13:30 | **신규진입 금지** — 거래량이 얇아 돌파 실패율이 높다 |
| 2차 진입존 | 13:30~14:50 | 동일 규칙 |
| 진입 마감 | 14:50 | 이후 신규진입 없음 |
| **강제청산** | **15:15** | 접속매매 안에서 전량 청산 (단일가 15:20 시작 5분 전) |

### 2.2 진입 조건 (전부 성립해야 함)

1. 개장레인지 확정 후 (09:15 이후)
2. 종가가 **개장레인지 고가 돌파** — 단, **돌파 봉에서는 진입하지 않는다**
3. 돌파 이후 종가가 **당일 VWAP 위**
4. ATR(14) 산출 가능
5. **비용 문턱 통과** — 목표수익 ≥ 왕복비용 × 3
6. 시간대 필터 통과, 당일 진입 횟수 < 2

### 2.3 진입과 동시에 확정되는 매도 계획

| 항목 | 값 | 근거 |
|---|---|---|
| 진입 | **지정가** = 현재가 − 0.3×ATR (눌림목 대기) | [자체판단·검증대상] |
| 지정가 유효 | 5봉. 미체결이면 취소 | [자체판단·검증대상] |
| **손절** | 진입가 − **1.0×ATR** | [자체판단·검증대상] |
| **익절** | 진입가 + **2.0×ATR** | [통념] 손익비 1:2 |
| **최대보유** | **60봉(60분)** — 안 움직이면 정리 | [자체판단·검증대상] |
| **최종청산** | 15:15 강제 | 세션 캘린더 |
| 투입비중 | 자본의 30% | [자체판단·검증대상] |

**손익비 1:2 → 손익분기 승률 33.3%.** 여기에 왕복비용을 얹으면 실질 손익분기는 그보다 높다.

### 2.4 왜 지정가인가 — 비용이 27% 줄어든다

| 진입 방식 | 진입 슬리피지 | 청산 슬리피지 | 수수료 왕복 | **왕복 합계** |
|---|---|---|---|---|
| 시장가 진입 + 시장가 청산 | 1.69bps | 1.69bps | 3.00bps | **6.38bps** |
| **지정가 진입** + 시장가 청산 | **0** | 1.69bps | 3.00bps | **4.69bps** |

단타에서 이 차이는 결정적이다. 대신 **미체결 위험**을 진다 — 5봉 안에 안 채워지면 그 기회는 버린다.

## 3. 비용 문턱 (cost gate)

> **비용이 싸다는 것과 아무 때나 들어가도 된다는 것은 다르다.**

목표수익이 왕복비용의 **3배**를 못 넘으면 진입하지 않는다.

- 왕복비용 6.38bps × 3 = **19.1bps 이상**의 목표여야 진입
- 목표 = 2.0×ATR 이므로, **ATR이 진입가의 약 0.1% 미만이면 그날은 아예 거래하지 않는다**
- 변동성이 죽은 날 억지로 매매해서 비용만 내는 것을 구조적으로 막는다

`scripts/test-kosdaq150.ts` [D] 에서 문턱을 극단으로 올리면 진입이 전부 차단되는 것을 검증한다.

## 4. 검증된 것 / 안 된 것

**검증됨 (18개 항목, 인공 봉)**
- 개장 15분 진입 0건 / 돌파 봉 추격 안 함 / VWAP 위에서만 롱
- 진입 신호가 손절·익절·최대보유를 **전부** 동반 / 손절 < 진입 < 익절 / 손익비 정확히 1:2
- 비용 문턱이 실제로 차단 / 점심 공백 진입 0건 / 일일 진입 상한
- `requireExitPlan=true` 엔진에서 거부되지 않음 / 오버나이트 0건

**검증 안 됨 — 실데이터가 필요하다**
- 이 전략이 **돈을 버는지** (가장 중요한 것이 검증 안 됨)
- 파라미터 기본값(0.3 / 1.0 / 2.0 / 60봉 / 3배)이 229200에 적정한지
- 229200의 실제 1분봉 ATR 크기 → 비용 문턱을 얼마나 자주 통과하는지
- 개장레인지 돌파가 실제로 유의미한 신호인지 (**아닐 가능성이 상당하다**)
- VWAP 필터가 성과를 개선하는지

## 5. 솔직한 경고

**이 전략은 아직 가설이다.** 논리적으로 구성했고 코드로 검증했을 뿐, 수익성 근거는 없다.

특히 우려되는 지점:

1. **개장레인지 돌파는 근거 강도가 약하다.** 미국 SPY 대상 ORB 연구는 존재하지만
   코스닥150 지수 ETF에 그대로 전이된다는 증거는 찾지 못했다.
2. **오버나이트 편중 가능성.** 코스닥 지수는 전일 종가 대비 시가가 오르는 확률이 극도로
   높았다는 자료가 있다. 미국 SPY 에서 확인한 것(오버나잇 t=3.05 유의 / 인트라데이 t=1.35 무의미)과
   같은 구조라면, **당일청산 롱은 애초에 불리한 시간대만 골라 잡는 것**이 된다.
   이것이 사실이면 전략 자체가 성립하지 않는다. **최우선 검증 대상(K6)이다.**
3. **파라미터 5개가 [자체판단]** 이다. 실데이터로 검증하고 불합격이면 폐기해야 한다.
   합격선을 사후에 완화하는 것은 금지한다.
